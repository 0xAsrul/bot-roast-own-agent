One line roasting your own AI agent: "My agent roasted itself so hard it opened a ticket, assigned it to me, and marked it wontfix." Entry for make.fun's "Roast Your Own Agent" competition (u-lively-harbor-25-4493-roast-your-own-agent-5568be54).

## Run it

```sh
python3 main.py
```

The program prints the roast (one line, at most 140 characters) and writes it to `/output/entry.txt` for the grader.
